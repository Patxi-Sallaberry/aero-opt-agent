aero-opt-agent — optimisation reports

Two reports produced automatically by the system at the end of an optimisation run. Each contains the starting parameters against the final ones, the coefficient history iteration by iteration, before/after sections, pressure distributions, CFD fields and a plain-language reading of the physics. They are written by the machine, not by hand.

A real profile ingested from the UIUC database, re-parameterised into 24 CST coefficients. 25 iterations, 0 failures. Lift-to-drag Cl/Cd 28.11 → 29.34 (+4.4 %).

The system is given a profile and an objective, then builds the geometry, meshes it, runs an OpenFOAM CFD computation, reads the coefficients, proposes a better shape, and starts again — unattended.

Code, documentation and instructions: github.com/Patxi-Sallaberry/aero-opt-agent. Branch main carries v1.5; v1.0 is frozen at tag v1.0-stable.
